## 核心代码及产品规则

- `data/models.js`：字段映射、原始资料、独立核验状态、参数缺失与版本提示；`data/model-assets.js`保留原素材映射。
- `utils/recommend.js`：纯函数、输入与车型类型校验、用途35/经验20/座高20/关注25、≥65阈值、车系去重、逐车排除追踪。
- `pages/index/index.js`及WXML：保留六问题流程，关注点修正为预算合适，接入真实结果、得分拆解和同系版本入口。
- `pages/compare/params.*`、`pages/detail/detail.*`：10项参数、来源日期、配置证据与版本提示；缺失显示官方数据待核验。
- `reports/result-quality.md`：12组画像TOP3与四项得分；JSON含全部候选、逐车排除原因、每项关注点分数、证据、异常及车系信息。
- `reports/business-findings.json`：耐用评分敏感性分析与待批准建议，源评分未修改。

预算遵循当前Excel规则：前三项仅最高价限制；“2万元以上”及未确定均无上限，不加最低2万元。未知价在有限预算下另列询价，不进TOP3。只选预算合适或0个有效关注项：**规则待用户确认，暂不生成排名，不分配25分、不除零**；允许返回补选已有非预算关注项。并列得分按车型ID稳定排序（未获其他同分偏好规则）。未定预算可包含缺价车型，卡片明确询价。
